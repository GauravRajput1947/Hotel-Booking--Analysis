# Hotel-Booking--Analysis
Built a Hotel Booking Data Engineering &amp; Analytics Pipeline using Snowflake + Power BI

🔹 What I built:

✅ Snowflake as the cloud data warehouse
✅ Bronze → Silver → Gold data architecture
✅ Raw booking data cleansing & standardization
✅ Date, duplicate & data-quality handling
✅ Monthly revenue & booking aggregations
✅ Top cities by revenue analysis
✅ Booking analysis by room type & booking status
✅ KPI calculations — Total Revenue, Total Bookings, Total Guests & Average Booking Value
✅ Power BI dashboard for interactive business reporting
